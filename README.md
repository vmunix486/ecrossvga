# ELKS Cross-VGA compatibility library

This is a simple project that I wanted to work on that helps bridge the gap between new and old, with the same functions doing the same things on both platforms. You can test on a modern computer, then compile for (ELKS)[https://github.com/ghaerr/elks], and test the same program on there, or at least that's the theory.

So far I have SDL 1.2 support, but I do want to add some *"less obsolete"* libraries as display output as well.
